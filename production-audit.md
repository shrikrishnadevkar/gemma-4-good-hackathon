## 🚀 DEPLOYMENT COMMANDS

### Vercel (Frontend)
```bash
npm run build
vercel --prod
```

### Environment Variables Required
```env
# AI Configuration
VITE_GEMMA4_API_KEY=your_gemma4_key
VITE_GEMMA4_ENDPOINT=https://api.gemma4.ai/v1

# Database (Production)
DATABASE_URL=postgresql://user:pass@host:5432/db

# Auth (Production)
VITE_CLERK_PUBLISHABLE_KEY=pk_...

# Vector DB
VITE_PINECONE_API_KEY=your_key
VITE_PINECONE_ENVIRONMENT=your_env

# Storage
VITE_FIREBASE_CONFIG=...
```

### Prisma Migrations
```bash
npx prisma generate
npx prisma migrate deploy
npx prisma db seed
```
